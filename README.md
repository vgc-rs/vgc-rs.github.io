# VGC-RS

Website of the VGC-RS group: events, results, photos, schedule and stores.

Built with [Eleventy](https://www.11ty.dev/). No front-end framework: HTML, one CSS file and a small script for the gallery, the standings modal and the filters.

Code is in English. Site content (copy, URLs, data values) is in Portuguese.

Original photos, original standings and the tools that prepare them live in the sibling project `vgc-rs-site-data`. This repository only holds the site and the files it publishes.

## Commands

```bash
npm install
npm start          # local server at http://localhost:8080
npm run build      # builds the site into _site/
```

## Structure

```
src/events/*.md               one post per event
src/_data/schedule.json       upcoming tournaments
src/_data/stores.json         stores
src/_data/players.json        player names, aliases and photos
src/_data/eventTypes.json     event types and badge colors
src/_data/ranking.json        Copa dos Campeões ranking, generated by the data project
src/standings/                published standings (image or PDF)
src/assets/site.css           tokens and styles
```

## File names

Everything is lower case, with dates as `YYYY-MM-DD`.

- Photos: `src/photos/YYYY-MM-DD/NNN.webp` and `NNN-thumb.webp`, generated by the data project.
- Standings: `YYYY-MM-DD-<event-type>[-<division>].<ext>`, for example `2026-09-19-league-cup.pdf`. A PDF replaces an image of the same standings.

## New event

1. Add the photos in the data project (`../vgc-rs-site-data`) and run `npm run photos` there. It writes `src/photos/` and `src/_data/photos.json` here, and the date links the photos to the post.
2. Create `src/events/YYYY-MM-DD-slug.md`:

```yaml
---
title: "League Challenge"
date: 2026-11-14
types: [league-challenge]
store: nerdz-cards
tournaments:
  - name: "VGC League Challenge Novembro 2026"
    type: league-challenge
    standings: /standings/2026-11-14-league-challenge.pdf
    divisions:
      - name: Master
        players:
          - { place: 1, name: "Fulano", record: "5-1-0" }
          - { place: 2, name: "Ciclano", record: "4-2-0" }
---

Optional post text.
```

`tournaments` is optional. A League Challenge or League Cup with more than one division also has `overall`, the names of all players in order, used by the Copa dos Campeões ranking. `venue` names a place that is not in `stores.json` and is shown when there is no `store`. `videos` is an optional list of YouTube links, shown below the photos; a `t=` in the link sets the start time. The first place of the first division is shown as the champion.

3. If the event has a League Challenge or League Cup, run `npm run ranking` in the data project to update `src/_data/ranking.json` (Copa dos Campeões).

## Schedule

```json
[
  { "date": "2026-11-14", "title": "League Challenge", "types": ["league-challenge"], "store": "nerdz-cards", "time": "13h", "signup": "https://..." }
]
```

Past dates drop out on the next build.

## Players

Players come from the standings. A player with a nickname, a photo or a name in more than one spelling gets an entry in `src/_data/players.json`, with the official name, an optional `nickname` shown everywhere except the standings tables, the other spellings in `aliases`, an optional `photo` (square webp in `src/assets/players/<slug>.webp`) an optional `majors` list (`{ place, events }`, place one of Campeão, Vice, Top 4, Top 8, Top 16 or Day 2) shown on the player page above the wins, and `hidden: true` to leave the player out of the player pages (the name stays in the standings). Every first place in any division counts as a win.
